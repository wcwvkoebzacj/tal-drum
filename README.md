## Overview

TAL-Drum is a twelve-channel sample drum machine with per-channel pitch, pan, volume, reverse, and individual audio output routing, designed for straightforward beat production.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **TAL-Drum** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **12 Channels** | 12 independent sample pads with sample browser and waveform preview |
| **Per-Channel Processing** | Pitch, volume, pan, and reverse per pad with output routing |
| **Step Sequencer** | 64-step grid with velocity per step and swing control |
| **Multi-Output** | Route individual pads to separate DAW tracks for mixing |
